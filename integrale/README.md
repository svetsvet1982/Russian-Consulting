## 시즌 요약
- **S1**: 같은 날 사직한 네 사람이 제빵 체인 사건으로 지주회사 Vauclair의 편취 구조를 파헤치고 «Cabinet Lutèce»를 세운다. 성공 뒤 위장 의뢰인 Brissac, 정보 유출, Antoine의 이탈과 잠입, 명예훼손 재판에서 부분 승리.
- **S2**: 유명해진 뒤 의원 Perrin·언론 소유주 Daurelle·옛 로펌 Delcourt의 유혹. 네 사람이 각자 규칙을 하나씩 어기고 스캔들로 무너지지만, 공개 고백으로 일어서 규칙을 7개로 늘린다.
- **S3**: 유럽검찰과 함께 국경을 넘는 네트워크 Atlas를 추적. Karim의 이직, 증인 Brissac의 실종, 후배 Théo의 배신과 고백, 총수 Rhein 체포, 그리고 세대교체와 1-1 장면의 거울 엔딩.
