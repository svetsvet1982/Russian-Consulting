## 알려진 미해결 불일치 (검수 시 확인)
- 문학 인용의 시구·연도는 대부분 제목/첫 행만 확신한 것이다(각 화 해설에 명시). 원문 대조 필요.
- 보이추크 나이: 5부 3화 54세(2019) 기준, 6부 3화 58세, 7부 59세로 대체로 맞췄으나 9~10부 일부 화에 61~62세 표기가 남아 있다.
- 시의회 미개최 기간: 7부 2화 '14개월', 7부 8화 603일, 7부 9화 '20개월' 등 화마다 다르다(2023-02 → 2024-10이면 약 20개월).
- 7부 7화·8화·9화·11화 사이 흐나튜크의 점검 명단 줄 번호가 다르다(4·7·11·15번째).
- 한나의 집 층수(5부 12화 3층 vs 8부 11화 5층), 시도렌코 계급·나이, 키릴로 나이(54/60/62세), 라이사 나이(70대/80대).
- 10부에서 빈니첸코 「Чесність з собою」를 위원회 표어로 여러 화가 되풀이해 인용한다(2화가 최초).
- 우크라이나어는 원어민 교정을 받지 않았다.
